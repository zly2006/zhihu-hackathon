# 演示数据集

这是一个完全虚构、仅用于开发验证的数据集，不是知乎真实内容，也不代表任何真实人物。

文件：`source_records.jsonl`

- 6 条 `SourceRecordV1`；
- 3 个问题场景，每个场景 2 条回答；
- 每条记录都有来源、回答身份、正文、主题、互动快照和原始载荷；
- 当前演示记录使用清洗后的纯文本正文；真实 HTML 来源必须同时填写 `content.raw_html`，系统会把它写入原始信封和内容快照；
- `manual_upload` 表示人工整理/合法导入，因此不需要自动采集授权；
- 正文内容只用于验证“原文 → 快照 → 后续情景分析”链路。

## 三组预期场景

| 场景 | 共同问题 | 对比路口 |
|---|---|---|
| 教育选择 | 本科毕业后先工作还是读研 | 工作优先 / 读研优先 |
| 职业选择 | 要不要从大厂转创业团队 | 保持稳定 / 转入创业 |
| 转行学习 | 转行数据分析是否报班 | 自学项目 / 付费训练营 |

这些“路口”只是人工标注的演示预期，不是系统已经自动推断出的结论。真正的抽取结果必须继续经过证据校验和人工审核。
