# Narrative KB 开发执行说明书

版本：V1.0

目标：

本说明书用于指导 Agent / DeepSeek 按照已经冻结的产品设计，实现
Interactive Narrative Knowledge Base（Narrative KB）。

本文件关注：

-   如何开发
-   开发顺序
-   文件结构
-   数据库实现
-   API实现
-   测试标准

不重新讨论产品设计。

------------------------------------------------------------------------

# 1. 项目目标

建立一个独立服务：

    narrative-kb

作用：

将：

小说文本 + Visual Novel文本

转换为：

结构化互动叙事知识。

最终服务：

AI人生模拟视觉小说 RPG。

# 5. 数据库实现

使用 PostgreSQL。

## 表1：narrative_fragment

保存核心叙事片段。

字段：

    id

    source

    title

    scene_type

    life_stage

    event

    conflict_type

    emotion_curve

    relationship_effect

    choices

    tags

    quality_score

    created_at

------------------------------------------------------------------------

## 表2：choice_pattern

保存选择模式。

字段：

    id

    type

    options

    effects

------------------------------------------------------------------------

## 表3：character_arc

保存人物成长。

字段：

    id

    character_name

    stage

    state_before

    state_after

------------------------------------------------------------------------

## 表4：embeddings

使用pgvector。

字段：

    id

    fragment_id

    embedding_type

    vector

# 7. Chunker开发

不要使用：

固定字数切割。

采用：

Event Based Chunking。

目标：

从：

章节

转换为：

人生事件。

例如：

输入：

    第100章

输出：

    毕业选择

    创业失败

    关系冲突

# 8. LLM Extractor开发

目录：

    prompts/

    ├── narrative_extract.md

    ├── scene_extract.md

    └── choice_extract.md

------------------------------------------------------------------------

## 核心Prompt要求

系统角色：

    你是一名视觉小说编剧和人生模拟游戏设计师。

    你的任务不是总结文本。

    你的任务是将文本转换为可玩的互动叙事知识。

------------------------------------------------------------------------

## 输出要求

必须JSON。

包含：

    scene_type

    life_stage

    characters

    trigger

    conflict

    emotion_curve

    choice_points

    relationship_effect

------------------------------------------------------------------------

# 9. Validator开发

所有抽取结果需要评分。

评分：

## 人生相关性

0-5

## 游戏性

0-5

## 情绪完整度

0-5

## 可迁移性

0-5

规则：

    score >=15

    进入Knowledge Base

# 11. API开发

FastAPI。

------------------------------------------------------------------------

## API 1

查询叙事素材

    POST

    /api/narrative/search

输入：

``` json
{
"event":"创业失败",
"stage":"career"
}
```

返回：

``` json
{
"scene_pattern":{},
"choice_pattern":{},
"emotion_curve":[]
}
```

------------------------------------------------------------------------

## API 2

生成Scene参考

    POST

    /api/narrative/scene

输入：

    event

    characters

    relationship

输出：

    scene_structure

    dialogue_style

    choices
