# 角色立绘验收标准

生成或替换角色立绘时，按 `docs/character-pose-prompts.txt` 的历史提示词执行，并逐项确认：

- 角色总数为八个：四男四女；每个角色都是独立的视觉小说角色。
- 每个角色是一张横向角色表，画布内正好有同一角色的三个全身姿态：站立、微笑、歪头并在眼角旁比 V。
- 三个姿态保持同一发型、服装、配色、配饰和身份；头身比例为约 2–2.5 头身的经典日系 Q 版。
- 所有头发、手和鞋都在画布内，不能裁切；画面不能出现文字、边框、标志或水印。
- 背景必须是真透明：文件带 alpha 通道，背景像素透明，不能把白底、深色底或棋盘格画进图片。
- 仓库交付格式为 `.webp`；每张图保持横向 1536×1024，并用 `webpinfo` 检查 `Alpha: 1`。
- 最终在本地页面逐张查看八张图，确认没有角色错配、姿态缺失、透明背景失效或明显画风/头身比例偏差。
