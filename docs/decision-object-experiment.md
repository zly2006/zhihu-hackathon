# 决策对象试跑报告

日期：2026-08-22

## 结论

这条链路已经能把真实知乎问题自动转换成可入库的 `DecisionObject`，并保留到回答 URL、HTML 和原始快照的完整回链。

首批采用高精度策略：不确定的数据自动排除，不进入正式对象表。

## 输入与版本

- 输入：100 个真实知乎问题，对应 429 条回答快照；
- 语言模型：`Qwen/Qwen3-4B-Instruct-2507`，RTX 4090 本地推理；
- COEL：OASIS COEL 1.0 官方 JSON；
- 提取版本：`decision-object-v1`；
- 输入 SHA-256：`949ef5ac99e907a7ad6d8bc1d621eae0797d1bbd6d7c5cf0c0080fca8240ac83`；
- COEL SHA-256：`56b6820fce3bad81815c7f1385cac8c748c7a4726291a5810ff87f1eff9963e8`。

## 自动质量门

正式导入必须同时通过：

1. 对象只能是“是否 + 行动”或“选择 + 对象/行动”，最多 18 字；
2. 置信度不低于 `0.90`；
3. 批次不能没有高置信对象，单一对象占比不能超过 25%；
4. 泛化对象自动排除；
5. COEL 只由本地高精度别名表挂接，模型输出不能决定编码；
6. 所有回答快照必须已存在，且导入可重复执行。

第二次导入同一产物的结果为：新增对象 `0`、新增归属 `0`、更新归属 `0`。

## 失败实验带来的修正

- `Qwen3-0.6B` 出现模板化塌缩和错误 COEL，因此没有入库；
- `Qwen2.5-1.5B` 能稳定输出 JSON，但语义判断偏差明显，因此没有入库；
- COEL embedding 召回会出现“买房 → 辞职”等跨语言误配，已从提取主链删除；
- 最终采用 4B 中文模型凝练对象，COEL 仅作确定性上位锚点。
