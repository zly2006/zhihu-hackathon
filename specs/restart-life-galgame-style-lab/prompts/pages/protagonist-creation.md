# 主角创建页

## 页面定位

- 页面 ID：`protagonist-creation`
- 游戏类型：现代都市成年人生模拟视觉小说 RPG
- 平台：桌面与手机
- 参考尺寸：桌面 1440×900，手机 390×844
- 页面目的：完成 18 岁主角档案并进入三位核心关系生成
- 主操作：`生成三位核心关系 →`

## 视觉约束

- 继承已确认场景页的浅色四边框架。
- 暖米白半透明纸张、香槟金细描边、深棕正文、低饱和砖红错误状态。
- 圆角 8—13px，轻微内高光与暖棕软阴影；避免玻璃科技感。
- 成人现代都市动画头像，克制赛璐璐质感，不校园化、不幼态化。
- 所有中文均由 HTML 排版，图片只承担人物视觉。

## 布局与组件

- 顶部：品牌、`序章 · 建立人生档案`、副标题 `18 岁是起点，不是判决`、草稿/帮助/返回入口。
- 左侧：可收起五阶段进度轨道——基本身份、出身起点、人格内核、初始天赋、最终确认。
- 中部：暖米白档案纸，包含完整 `ProtagonistDraft` 字段、预设卡、多选标签、头像选择与 250 点天赋分配。
- 右侧：可收起的真实人物头像、18 岁身份摘要、人格标签、长期目标、天赋条和初始困境。
- 底部：返回、保存/清空草稿、草稿状态和主操作。
- 手机：进度轨道变为顶部五段横条，右侧预览隐藏，表单单列，底部主操作固定。

## 状态

- `default`：加载完整示例档案，便于直接检查视觉。
- `editing`：输入与右侧摘要实时同步。
- `incomplete` / `invalid`：字段级错误与顶部错误摘要。
- `draft-restored`：从 `restart-life-protagonist-draft-v1` 恢复。
- `submitting`：模拟 1.2 秒关系生成；不调用 API。
- `panel-collapsed`：左右面板独立收起。
- `mobile`：390×844 单列预览。

## 图像生成提示词

构建一个 1440×900 的中国现代都市成年人生模拟视觉小说 RPG 主角创建页。采用统一浅色 Galgame 四边框架：顶部暖米白指令栏、左侧五阶段人生档案进度、中央纸张质感结构化表单、右侧成年动画人物头像与实时摘要、底部主操作栏。色彩为暖米白、香槟金、深棕与少量低饱和砖红，材质细腻克制，圆角 8—13px，香槟金细描边，柔和暖棕阴影。中央表单展示基本身份、出身起点、人格标签、价值观、长期目标、初始困境、六个头像选项和五项 0—100 天赋预算。所有文字使用清晰 HTML 中文排版，按钮具有明确可点击质感，信息层级一眼可读，与已批准的都市现实动画场景实验台保持同一设计系统。

## 反向限制

- 不生成乱码、错误汉字、商标、未经授权角色或可识别真人。
- 不使用姓名首字、纯色圆点或“你”代替人物头像。
- 不使用黑夜侧栏、霓虹赛博、蓝紫科技玻璃、金属机甲或高饱和手游大厅风。
- 不让头像遮挡表单，不让按钮变形、粘连或失去层级。
- 不使用校园制服、幼态面孔或未成年视觉语境。
- 不把家庭背景、性格或头像展示为固定成功率奖励。
- 不在图片内固化中文；不调用在线字体、CDN 或远程图片。
